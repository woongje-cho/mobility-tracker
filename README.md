# 모빌리티 전략 원장

로보택시, 휴머노이드, 소프트웨어 중심 자동차(SDV)를 만드는 회사들이 공개적으로 내건 목표를 기록하고, 규제기관 자료와 공시로 결과를 대조하는 개인 프로젝트입니다. 현대차그룹을 중심에 두고 봅니다.

- 사이트: https://woongje-cho.github.io/mobility-tracker/
- 전체 데이터: [`tracker.json`](tracker.json)

## 읽는 법

- 모든 숫자에는 출처 종류(T1 규제기관·공시, T2 회사 발표, T3 언론·집계·자체 계산)와 원출처 확인 여부가 붙어 있습니다.
- 약속은 결과로 판정하고, 판정마다 근거를 한 줄 남깁니다. 근거가 부족하면 판정을 보류합니다.
- 새 값은 덮어쓰지 않고 이력으로 남깁니다.

## 틀린 곳을 발견하면

출처와 함께 이슈로 남겨 주세요.

## 고지

공개된 자료만으로 만든 개인 프로젝트입니다. 투자 조언이 아니며, 언급된 회사의 공식 입장과 무관합니다. 인용한 수치는 각 원출처의 이용 조건을 따릅니다.
